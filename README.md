# PHONE LIFE 通用空白版

一个可以直接打开、也可以拉取源码自行修改的本地手机生活模拟器。此版本保留手机及应用交互，移除了原版的消息主线、人物阵容、聊天记录、来信、社交历史和固定开场剧情。默认不自动发消息；可选择连接自己的模型服务，让 AI 扮演角色并实时修改人物、聊天、动态和日程。

版本：1.2.0。默认解锁密码：`0709`。默认玩家名：`我`。这是独立工程，不会读写原版的存档键或媒体数据库。

**可选 AI：** 从“设置 → AI 控制台 / AI 连接与权限”进入。首次使用按 [AI 启动说明](docs/AI_SETUP.md) 配置后端；Windows 可运行 `AI_START.cmd`。AI 默认关闭，原有离线功能仍然可用。

**脚本与手动编辑：** 从“设置 → 内容工作室”导入自己的脚本，AI 识别后生成待核对的跨应用剧情草稿；安装后立即送达开场消息。也能离线补写双方聊天、修改剧情分支、编辑各平台帖子与媒体描述。见 [完整工作室说明](docs/SCRIPT_STUDIO.md)。默认不附带可玩的剧情。

## 1. 直接使用

1. 解压整个文件夹，双击最外层的 `index.html`，用现代桌面浏览器打开。无需安装 Python、Node.js 或第三方包。
2. 在入口页选择“进入我的手机”或“直接进入手机”，到锁屏上滑，输入 `0709`。
3. 想先修改身份，选“编辑人物与关系”；之后也可从“设置 → 人物与世界”进入。
4. 在“人物与世界 → 人物”添加家人、好友、同事等。联系人与私聊会同步创建，消息列表起初为空。
5. 从照片、备忘录、音乐、社交应用等入口添加自己的内容。没有导入照片、视频或音频时，相应列表为空是正常现象。
6. 离开前，在“设置 → 导出存档”保存自己的 JSON 备份。迁移文件夹、换浏览器或清理浏览器数据前尤其需要备份。

这里只包含本地模拟流程。发私信、发邮件、购物、拨号不会连接真实平台或产生真实交易。相机和录音仅在你主动点击启用时请求浏览器权限。

## 3. 常用操作

### 设置身份、人物和账号

- “设置 → 人物与世界 → 档案”：保存姓名、显示名、职业/团队等。年龄、活动方式等结构字段仍保留，日常和爱豆设定均可自行填写。
- “人物”：按关系分组添加和修改人物；点击人物旁的聊天按钮进入会话。恋爱关系由使用者自行选择。
- “账号”：修改 Instagram、X、Threads、TikTok 的显示名、用户名和账号类型，也可添加更多账号。帖子、草稿、私信、关注与收藏分别保存。
- “设置 → 解锁密码”：先输入当前密码，再输入并确认四位新密码。默认密码 `0709`；网页 PIN 只模拟解锁体验，不是数据加密。

### 聊天、群聊与附件

先添加联系人，再进入 KakaoTalk 私聊。输入框支持自由文字。空白版会保存你发出的内容，不会套用原版的 NPC 固定回复。

点击 `＋` 可选择照片、输入照片描述、发送文件/位置或导入语音文件。文件单个不超过 20 MB；位置由自己填写地点和说明，不会自动读取真实定位。实际文件保存在浏览器媒体数据库。

从聊天页右上角或开放聊天入口创建群。私有群至少选择两位已有联系人；设置群名称、简介与成员后创建。群内同样不注入固定回复。想加入自己的 NPC 对话规则，可修改 `src/template-runtime.js`，或接入自己编写的可选消息文件。

### 发布社交内容与直播

从对应应用的发布入口填写文字，选择实际图片/视频，或使用提供“描述画面”的入口。文字描述会作为描述卡显示，不冒充实际照片。

Weverse LIVE 可输入场景文字代替视频，也可导入本地视频或主动启用摄像头。可以在直播中更新场景、发言并保存直播记录；默认没有自动观众弹幕。相机画面不会自动录制成视频文件。

### 音乐与本地文件

在音乐页右上角 `… → 导入新歌曲` 选择本地音频。曲名初取文件名，元数据和音频关联随存档保存。已有歌曲的更多菜单可以重新关联音频；也可以建立播放列表、收藏歌曲和调整播放队列。

照片/文件/语音备忘录分别提供自己的导入入口。导入是否成功取决于浏览器支持的文件格式与可用存储；跨应用分享使用同一份本地媒体，删除前确认是否还被其他内容引用。

### 商城、外卖与卡片

1. 商城选品牌 → 商品 → 规格/数量 → 购物袋或立即购买；外卖选商家 → 餐品/口味 → 购物袋。
2. 结算页确认金额、收货地址、收礼对象和付款卡。外卖未达到起送金额时需继续加购。
3. 在卡片管理中添加、命名他人的模拟卡；初次安装只有玩家自己的卡，余额为 `₩50,000,000`。
4. 确认支付后，从订单页查看处理/配送、取消/退款等可用操作。通知、收据和灵动岛在相应状态联动。
5. 给别人送礼/点餐前，先添加关系人物或收礼联系人。彩蛋属于操作反馈，不会替你建立默认恋爱关系。

## 4. 存档、备份与原版隔离

文字与状态使用 `localStorage`，实际媒体使用 `IndexedDB`。本版默认键为 `phone-life-blank-v1-blank-state`，媒体库为 `phone-life-blank-v1-blank-assets`，不会读取原版的 `idol-phone-life-*` 数据。

“设置 → 导出存档”导出包含状态及已保存媒体的 JSON；“导入存档”读取本通用版格式。原版存档不会自动导入，避免把原版剧情和私人记录带入空白版。大文件较多时备份会明显增大。

打开同一项目的根目录 `index.html` 和 `project/index.html`，或移动文件、换浏览器/域名/端口，浏览器可能使用不同的存储空间。建议始终使用同一个根目录入口；迁移前导出，再在新入口导入。清除站点数据、无痕窗口退出或存储被浏览器回收，都可能使本地记录消失。

源码包和 ZIP **不包含你浏览器中的实际游玩存档**。当前原版的源文件已另存工程快照，但要把浏览器里的游玩记录也备份下来，仍需在原版设置中导出。通用版重置仅清除自身的状态和媒体。

## 5. 拉取、修改与重新生成

本目录是独立的 Git 工程。可以下载 ZIP，也可以从公开仓库拉取：

```text
git clone https://github.com/Mavis779-creator/phone-life-generic.git
cd phone-life-generic
```

只玩已生成的 `index.html` 不需要开发环境。修改源码或 JSON 后重新生成，需 **Python 3.10+**，仅使用标准库。测试另需 **Node.js 20+**，无需 `npm install`。

```text
python scripts/build.py --validate
python scripts/build.py
python tests/config_test.py
node tests/template.cjs
node tests/ai.cjs
node tests/ai-server.mjs
node tests/authoring.cjs
node tests/authoring-server.mjs
```

Windows 也可以双击 `BUILD.cmd`，或 `CHECK.cmd` 构建并运行检查。若命令行只有 `py`，使用 `py -3 scripts/build.py`。macOS/Linux 的命令通常是 `python3`。

测试以本包的默认空白配置和商品目录为基准；主动修改初始内容或商品数量后，需同步调整相应测试预期。打包自己的修改版可运行 `python scripts/package.py`，ZIP 位于 `dist/`，自动排除缓存、检查输出和 `saves/`、`backups/`。

构建输出为根目录 `index.html`、`project/index.html` 和 `BUILD_INFO.json`。运行时不读取 JSON 文件，配置已嵌入 HTML，所以直接打开也不依赖网络。**改 JSON 后必须重建，再刷新页面。**

修改入口：

| 想改什么 | 文件 |
| --- | --- |
| 标题、玩家默认信息、PIN、初始联系人、壁纸、余额、桌面布局 | `config/phone.config.json` 的 `overrides`；默认值见 `config/presets/blank.json` |
| 存档命名空间 | `config/phone.config.json` 的 `storageNamespace` |
| 默认曲库元数据 | `config/music.library.json` |
| 自己编写的消息内容 | `config/scenario.json`，默认空且未启用 |
| 商品、价格、规格 | `src/assets/shop/catalog.json` |
| 外卖商家、餐品、配送规则 | `src/delivery.js` |
| 原生应用布局/交互 | `src/` 中对应应用的 `.js` / `.css` |
| 空白版初始化、无自动回复策略、入口 | `src/template-config.js`、`src/template-runtime.js` |
| 构建与配置检查 | `scripts/build.py`、`scripts/template_config.py` |

完整配置说明见 [docs/CONFIGURATION.md](docs/CONFIGURATION.md)；自写消息的数据结构见 [docs/AUTHORING.md](docs/AUTHORING.md)。这些说明没有附带可玩的剧情预设。

不要把生成的 `index.html` 当作主要源码编辑；下一次构建会覆盖它。`project/CURRENT_BASELINE_v0_6.html` 是组装用历史骨架，配置数据已清空，其行布局仍被构建脚本使用，不建议直接重排行。优先在 `src/` 和 `config/` 修改。

## 7. 常见问题与边界

- **进入后没有消息？** 这是空白版的预期行为。没有预置联系人、剧情、自动回复或定时来信。要有对话需自己添加内容/规则；可选 AI 接口可在设置中开启，见 AI 启动说明。
- **改了默认名字或联系人却没有变化？** 默认配置只用于新存档，不强行覆盖玩家已经编辑的内容。可以在页面中修改；或者先导出备份，再重置本版；开发新作品也可换一个独立 `storageNamespace`。
- **改文件未生效？** 先构建，再刷新正确的根目录入口。确认没有打开原版或旧的复制文件。
- **导入音频没有声音？** 检查格式是否被浏览器支持、音量、自动播放限制；手动按播放。空曲库没有可播放音源。
- **摄像头/麦克风无法开启？** 本地文件环境、浏览器权限或设备占用均可能限制调用。文字描述或本地文件模式仍可使用。本项目不自动授权设备。
- **上传/保存失败？** 检查存储空间与浏览器限制；先导出可用存档。大量媒体更容易达到配额，文件过大时不要反复导入。
- **离开网页后还会推进吗？** 网页关闭后没有后台进程；再次打开时，订单等已持久化状态按时间结算。浏览器可能限制后台标签页的定时器。空白版不生成离线聊天。
- **可以连真实服务吗？** 当前没有真实社交账号登录、支付网关、真实邮件、外卖下单、手机通信或跨用户同步。AI 是单独的可选模型连接。接入这些服务属于额外开发。
- **可选消息能自动写无限剧情吗？** 不能。仅执行作者提供的节点、依赖、选项与文本变体，作者节点模式不使用生成式 AI；可选 AI 模式按玩家指令生成。
- **验证到了什么？** 本次检查覆盖配置约束、单文件脚本、空状态页面渲染、存档隔离、联系人/群聊、PIN、导入曲库元数据等逻辑；使用模拟 DOM/媒体/存储的 Node VM，不等于真实浏览器视觉或摄像头、录音、IndexedDB 设备验收。新环境仍需自行检查实际显示与权限。

应用图标和部分商品照片沿用原工程的本地素材，来源与哈希记录在 `src/assets/` 的清单中；默认离线模式无运行时 CDN 依赖。品牌标识、商品图及用户自行导入的音视频，其权利不会因为本包可下载而自动转让。见 [docs/ASSETS.md](docs/ASSETS.md)。本包未擅自附加 MIT 等代码授权声明。

分享源码或 ZIP 前，确认没有放入自己的存档、私照、录音或访问密钥。`.gitignore` 已排除常见备份/临时目录，但不会替你审查自己新添加的文件。发布时只需提供此工程；原版工程快照和自己的游玩存档应独立保管。
