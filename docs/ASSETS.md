# 素材与来源记录

本通用版复制了原工程当前可用的本地应用图标及商品展示素材，没有把用户参考截图、私照、浏览器游玩数据或下载的需求文档一起打包。

| 路径 | 内容 |
| --- | --- |
| `src/assets/app-store/manifest.json` | 应用图标、对应来源信息及文件 SHA256 |
| `src/assets/apple-system/manifest.json` | 系统应用图标素材记录 |
| `src/assets/weverse-app-store-source.json` | Weverse 图标来源记录 |
| `src/assets/shop/catalog.json` | 商品、规格、韩元标价、来源及检查日期 |
| `src/assets/shop/manifest.json` | 商品展示图及 SHA256 |

构建会校验清单哈希并把已有图标、商品图嵌入离线 HTML。清单来源是开发核对记录，不代表本通用版重新在线确认了所有当前价格。部分商品价格由原工程手动设定；品牌、商品型号、目录价格均可按自己的作品需要修改。

图标和商品图的品牌/版权归属不因打包而改变；没有在本包中授予额外的第三方素材许可，也未自行添加 MIT 等代码许可。若要公开发布自己的修改版，需要自行确定代码及素材的适用授权，并处理自己添加的照片、音视频和其他内容的权利。

源码中个别历史内部键如 YouTube 频道 ID `mavis` / `lumi` 仍是兼容实现标识，不代表当前用户身份或预置人物。空白版的公开名称、账号、消息和历史由 `template-config.js` 初始化为自己的空白资料。
