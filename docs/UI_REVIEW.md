# 应用界面检查与本轮调整

版本：1.3.0。范围为通用版的 25 个桌面应用、开始页、内容工作室及连接工具。原版工程和玩家浏览器存档不参与改写。

## 检查方式与边界

本轮完成源码样式清点、页面结构检查和模拟 DOM 的空状态/有内容状态渲染。以用户此前提供的 KakaoTalk、Gmail、音乐等截图为结构参考，另核对官方应用页面的身份和功能说明。**这些检查不等于逐页真实浏览器截图、实际点击区域测量或与最新版原生应用像素对照。**

字号清点仅针对 `src/*.css` 的声明，不是计算后的最终字号。调整前共有 335 处小于12px的声明，其中334处为非装饰文字；这些非装饰文字声明已提高到至少12px。保留的装饰性例外不作为正文使用。正文、输入框与主操作另按页面角色设置更大的字号。报告分别见 `UI_AUDIT_BASELINE.json`、`UI_AUDIT_CURRENT.json`。

采用的尺度：主要文字15–17px、聊天16px、输入框16px、次要信息12–13px；主要导航、图标与常用操作尽量提供44px高度。七列日历、内联文字操作等不能据此声称所有目标都达到了44×44。图标优先修正轮廓粗细；1px分隔线作为正常层级保留，不统一改成粗黑框。

依据：[Apple UI Design Dos and Don’ts](https://developer.apple.com/design/tips/) 建议提供清楚的文字、对比和足够的触控空间。官方身份/功能参考：[KakaoTalk](https://apps.apple.com/us/app/kakaotalk-messenger/id362057947)、[Gmail](https://apps.apple.com/us/app/gmail-email-by-google/id422689480)、[Weverse](https://apps.apple.com/us/app/weverse-connect-with-artists/id1456559188)。官方网页文本不作为截图视觉核验。

## 减少日常页面的工具提示

移除KKT头部常驻的AI快捷按钮；连接和创作功能仍从设置可达。聊天进度提示改为自然短句，去掉重复的“普通回复自动出现”等说明。日常通话不常驻显示媒体来源/模拟原理，设置和README保留游戏内操作说明。保存失败、权限和连接错误仍保留清楚提示。

创作工作室与连接设置继续明确模型功能和数据发送要求，不通过隐藏提示掩盖收费接口或错误。操作文案减少不改变真实能力：社交、邮件、购物、地图和通话没有变成真实服务。

## KKT语言与姓名

入口：**KakaoTalk 设置 → 聊天语言**；会话菜单和连接设置也可打开。

- 默认“中韩双语”：新生成的角色原文为自然韩文，下方为对应中文；玩家原话不改写。
- “仅中文”：新生成角色回复为中文，已有韩文消息用保存的译文显示。
- 旧消息没有译文时，明确标明并允许查看原文；不偷偷请求模型补译，不伪造译文或覆盖原记录。
- 选项对方回应为韩文时，剧本选项增加第4项中文译文；旧三项中文选项继续兼容。四项选项包需要1.3及以上版本。
- 新生成的人物使用中文姓名，原文姓名可放简介、账号handle仍可保留原文。已有用户命名不自动覆盖，旧英文姓名可手动编辑或主动要求创作助手整理。
- 前后端都校验新生成内容。不符合所选语言/中文姓名规则时本轮不应用，显示原因；不靠切换显示掩盖不合格的生成内容。

更新后若使用模型，请重新启动 `AI_START.cmd` 并填写当前连接码，使服务端也使用新规则。
