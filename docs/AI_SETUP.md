# AI 角色与实时手机内容

1.2 版包含可选 AI 控制台、角色回复和脚本编排。初次打开仍然是空白手机，AI 默认关闭，没有预置人物、消息或剧情。

## 功能与入口

| 入口 | 能力 |
| --- | --- |
| 设置 → AI 控制台 | 自然语言创建/修改人物、设置人格、创建群聊、发送角色消息、发布动态、添加/修改日程、更新关系记忆 |
| KakaoTalk 聊天页的 AI 按钮 | 带上当前会话进入控制台，按聊天内容继续安排 |
| 开启自动回复 | 在 KakaoTalk 私聊/群聊、已有人物的 Instagram/X/Threads/TikTok 私信、Weverse 私人来信中，发送文字后触发角色回复 |
| 撤销上次修改 | 撤销最近一批操作，最多保留五批；不覆盖后来手动修改过的同一内容 |

例如可以要求：“创建两位我自己设定的朋友，建立周末群，安排明晚聚餐，再让其中一位发一条动态。”名字、职业和性格由你的指令决定。

自动回复只在当前会话、当前账号、实际参与人物范围内发言，不自动公开私聊或改日程。跨应用安排使用控制台指令。每轮最多 20 项操作，自动回复最多两条，不会自行无限续写。

## 本地启动

1. 安装 Node.js 20 或更新版本，不需要 `npm install`。
2. 复制根目录 `.env.example` 为 `.env`，不要命名成 `.env.txt`。
3. 在 `.env` 填写自己的接口配置：

```text
OPENAI_API_KEY=填写自己的密钥
OPENAI_MODEL=填写接口提供方给出的可用模型ID
OPENAI_BASE_URL=https://api.openai.com/v1
AI_API_STYLE=responses
PHONE_HOST=127.0.0.1
PHONE_PORT=8787
```

真实密钥只放在本地 `.env` 或后端环境变量，不发到聊天、不写进 HTML 或公开配置。Git 和打包工具会排除 `.env`、`.env.*`，仅保留空的 `.env.example`。

4. 双击 `AI_START.cmd`，或运行 `node server/ai-server.mjs`。
5. 保持启动窗口打开。窗口显示手机地址 `http://127.0.0.1:8787` 和随机连接码。
6. 用浏览器打开该地址，进入“设置 → AI 连接与权限”，填写服务地址、连接码和模型 ID（模型也可由后端提供）。
7. 按需要启用 AI、自动回复和允许修改的类别，测试连接，再保存。
8. 在控制台输入指令。需要读取某段聊天时选择人物/群聊和平台；默认“不读取聊天”。完整响应返回后，一次性同步到原应用并保存。

连接测试只检查后端状态，不调用付费模型。实际生成需要你的模型权限与接口额度。本项目不附送 AI 额度，也没有把任何真实密钥打包。

从 `file://` 打开也可以填写本地服务和连接码；若浏览器限制本地网络请求，优先用后端提供的手机地址。切换入口前先导出存档，再到新入口导入，因为文件入口与本地网址可能使用不同存储空间。

## 接口与远程部署

默认使用 OpenAI Responses 的严格函数工具调用，工具名 `propose_phone_changes`。后端取得操作提案，浏览器再次校验后执行，不把模型文字作为 JavaScript 运行。

支持函数工具调用的 Chat Completions 兼容接口可配置：

```text
OPENAI_BASE_URL=https://你的接口服务/v1
AI_API_STYLE=chat
OPENAI_MODEL=该服务支持的模型ID
```

Base URL 不要追加 `/responses` 或 `/chat/completions`。远程模型服务需要 HTTPS。有些兼容服务不支持严格工具、`max_completion_tokens` 或指定模型，遇到这种情况会报错并保留原内容。

`AI_MAX_OUTPUT_TOKENS` 默认 6000，范围 1024–12000。后端设有超时、请求频率和并发限制，不自动重试失败请求；过长指令应拆分。

GitHub 仓库/静态网页不会替玩家运行 Node 后端。远程网页要使用 AI，需另行部署后端并提供 HTTPS 地址，例如按部署环境设置：

```text
PHONE_HOST=0.0.0.0
PHONE_PORT=8787
PHONE_ALLOWED_ORIGINS=https://你的手机网页域名
PHONE_AI_TOKEN=自行设置足够长且保密的连接码
```

允许来源填写精确的协议、域名和必要端口，多个用英文逗号分隔。连接码只交给允许使用该后端的人，不写进公开网页。当前后端适合个人/小范围自部署；多人公开运营还需要自己的用户登录、个人额度与账单管理。项目没有自动部署云端后端。

## 从自己的脚本编排剧情

在“设置 → 内容工作室 → 脚本导入”选择 TXT/MD 或粘贴正文。点击编排才发送正文、改编要求和可编辑提示词，不附带整部手机存档。AI 结果先进入草稿；核对人物、信息边界、分支与各平台联动，确认后安装。也能不接 AI，直接手写对话和帖子。完整格式与步骤见 [内容工作室](SCRIPT_STUDIO.md)。

脚本编排单独使用 `AI_SCRIPT_MAX_OUTPUT_TOKENS=16000`，后端超时约三分钟；普通 AI 仍用 `AI_MAX_OUTPUT_TOKENS`。长篇分章节处理，输出截断或格式校验失败不会替换旧草稿。

## 数据、权限与恢复

- 控制台提供玩家档案、人物性格/关系、当前平台账号概要、近期可见动态、日程，以及你选定聊天的最近 25 条文字。
- 自动角色回复只提供本会话参与者与会话文字，不提供其他私信、人物、日程或其他平台动态。
- 不自动读取密码、付款卡、收货资料、邮件、文件内容或图片/音视频原件。模型仅可读取已有文字说明。
- 连接码只保存在本次页面内存，不写入存档；刷新后需重新填写。API Key 从不进入浏览器。
- 人格保存在人物数据里，关系记忆保存在关系记录里。模型只看到本轮选取的上下文，不保证记住所有历史。
- 任一操作无效、目标不存在、账号不符或保存失败，整批回滚。生成期间相关内容被手动修改，会拒绝旧结果。
- “停止生成”取消本轮，迟到的响应不会写入。撤销使用逐项差异，可以保留无关的新便签；同一内容已有后续修改时，可能拒绝整批撤销，防止覆盖。
- AI 不覆盖作者主线正在等待选择的消息或主线日程。后台回应不重新挂载正在编辑的非聊天表单或播放中的音乐/视频，正常返回页面时显示新内容。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 连接失败 | 确认启动窗口还在、端口一致、浏览器允许请求该地址 |
| 连接码不正确 | 用当前启动窗口的码，重新启动后随机码会改变 |
| 后端未配置密钥 | 检查 `.env` 的文件名、密钥和模型，重启后端 |
| 模型返回 401/403 | 检查模型服务密钥、项目和模型权限 |
| 429 | 等待后重试，检查额度与请求频率 |
| 没有完整操作提案 | 缩小指令或换支持函数工具调用的模型 |
| 生成期间内容变化 | 基于最新内容重发指令，旧结果不会覆盖修改 |
| 自动回复没回应 | 确认连接码、自动回复和消息权限已开启，人物已添加；控制台可查看失败记录 |
| 刷新后不能回复 | 连接码不存档，需重新填写 |
| 新地址像全新手机 | 原入口导出，在新入口导入同一份通用版存档 |

## 验证范围

检查覆盖共享协议、批次执行/撤销、账号隔离、上下文筛选、失败回滚、本地 HTTP 认证和 CORS，以及“模拟器 → 本地后端 → 模拟模型 → 手机状态保存”的完整流程。

没有配置真实 API Key，没有调用真实付费模型；未验证你账号的权限、费用、真实模型质量或浏览器视觉布局。可运行 `node tests/ai.cjs` 和 `node tests/ai-server.mjs`、`node tests/authoring.cjs` 和 `node tests/authoring-server.mjs` 重复无付费模型测试。

实现依据：[OpenAI 工具调用](https://developers.openai.com/api/docs/guides/function-calling)、[OpenAI API 密钥要求](https://developers.openai.com/api/reference/overview#authentication)。
